🎭 MOOD.AI — Facial Expression Analyzer

MOOD.AI is an AI-based facial expression analysis project built using Python, Streamlit, OpenCV, and DeepFace.

✨ Features

- Facial expression analysis using AI
- Interactive web interface built with Streamlit
- Python-based image processing
- Visual presentation of analysis results

🛠️ Technologies Used

- Python
- Streamlit
- OpenCV
- NumPy
- Pandas
- DeepFace

🚀 Installation

1. Clone this repository:
   
   git clone https://github.com/eshwars2131/MOOD-AI.git
cd MOOD-AI

2. Install dependencies:
   
   pip install -r requirements.txt

3. Run the application:
   
   streamlit run app.py

⚠️ Disclaimer

Facial expression predictions are estimates and may be inaccurate. They do not reliably determine a person's actual mood.
